Designed for infrastructure you control

Local first by design.

RackMarshal is designed to operate without turning your infrastructure telemetry into a dependency on somebody else's hosted service.

Local operationRun RackMarshal on infrastructure you control.
Durable operational historyPreserve state instead of relying only on transient alerts.
Evidence-based incidentsTrack observations and events associated with failure and recovery.
Configuration-driven monitoringDefine how RackMarshal interacts with your environment.
Reproducible deploymentInstallation, configuration and database migrations are designed to be repeatable.
Minimal external dependenciesCore operation does not depend on a hosted monitoring service.

Built in a real environment, not just designed on paper.

RackMarshal grew from a working homelab operations system and the need to understand Proxmox, ZFS, backups, Linux infrastructure, hardware and other systems as a whole.

RackMarshal 1.0 turns that system into a reproducible open-source platform for homelabs, self-hosted infrastructure, edge systems and small infrastructure environments.

Important current boundary

A successful base installation proves the RackMarshal runtime, database, status API and notification queue can run. It does not automatically configure access to Proxmox, PBS, Home Assistant, ZFS, hardware or mount targets.

Those integrations require site-specific configuration and credentials. The installer does not copy production credentials or discover your infrastructure automatically.

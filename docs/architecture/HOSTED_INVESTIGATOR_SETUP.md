# Hosted Investigator setup boundaries

The distributed local plugin combines the portable policy with a loopback MCP configuration for local clients. It contains no hosted app identifier, tunnel identity, credential, or workspace binding. A local plugin test does not prove combined cloud import.

For hosted use, deploy the read-only MCP server behind an authenticated private connection supported by the runtime. Configure your own connection and verify exactly eleven read tools. Install the portable Investigator policy, bind it to that actual connection in your private copy, then test health/status, typed evidence, lifecycle/recovery, unsupported resources, incomplete evidence/pagination, and refusal of infrastructure/manual closure actions. Do not publish your binding.

The release does not claim qualification of combined cloud plugin import, implicit activation, every provider, or workspace-wide distribution. Keep the separate connection and policy installation path until a combined package is installed and evaluated in the target cloud environment. Core functionality does not require hosted AI.
